# LibriSphere - Multi-Vendor Bookstore E-Commerce Platform

## Overview
LibriSphere is a multi-vendor bookstore e-commerce application built using Spring Boot. It allows vendors to manage books, customers to browse and purchase books, and administrators to manage vendors and monitor platform activities.

## Features
- Multi-Vendor Management
- Buyer Shopping Cart
- Order Management
- Admin Dashboard
- Authentication & Authorization
- Responsive UI
- H2 Database Integration

## Tech Stack
- Java 21
- Spring Boot
- Spring Data JPA
- Hibernate
- Thymeleaf
- HTML
- CSS
- JavaScript
- H2 Database
- Maven

## Run the Project

```bash
mvn spring-boot:run
```

Open your browser:

http://localhost:8080
